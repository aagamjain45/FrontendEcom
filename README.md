LuxeCart is a sophisticated, high-performance e-commerce platform built with modern web technologies. It features a minimalist design philosophy, focusing on user experience, smooth transitions, and a premium aesthetic.



## ✨ Features

- **🌙 Dynamic Theme System**: Full Dark/Light mode support with persistent state across sessions.
- **🛒 Advanced Shopping Cart**: Seamlessly add, remove, and update quantities with real-time total calculations.
- **💖 Wishlist Integration**: Keep track of your favorite items with a dedicated wishlist system.
- **📱 Responsive Design**: A mobile-first approach ensuring a flawless experience on all devices.
- **🔍 Detailed Product Views**: Comprehensive product information, including high-res imagery, ratings, and reviews.
- **💳 Multi-step Checkout**: A polished, intuitive checkout flow for a friction-less purchasing experience.
- **👤 Personalized Profile**: User dashboard to manage orders, addresses, and personal settings.

## 🚀 Tech Stack

- **Core**: React 19 (Hooks & Context API)
- **Tooling**: Vite (Fast HMR & Build)
- **Routing**: React Router 7
- **Styling**: Vanilla CSS (Custom properties & Flex/Grid)
- **Icons**: Lucide React
- **Storage**: Browser LocalStorage for persistence

## 🛠️ Project Structure

```text
src/
├── components/     # Reusable UI components (Navbar, Footer, Hero, etc.)
├── context/        # Global state management (Cart, Theme, Wishlist)
├── data/           # Mock data and constants
├── pages/          # Full page layouts (Home, Cart, Checkout, etc.)
├── assets/         # Static assets and global styles
└── App.jsx         # Main application entry and routing
```

## 🏁 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/luxecart.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
